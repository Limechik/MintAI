# Vox — что взято из VoxSynth и что добавлено

Взято без изменений: `FormantCore.c/.h`, `Phonemes.c/.h`, `Stress.h`.
`Stress.c` — тот же словарь + добавлены числительные (11–19, десятки, сотни, «тысяча/миллион/
миллиард» во всех формах), «процент», «запятая», «точка»: их озвучивает нормализатор чисел,
а при ударении «на последнюю гласную» они звучали бы неправильно.
Новое: `MAVoxCore.c/.h` (нормализация текста, предложения, тембр, громкость).

Не использовано: `VoxSynth.m/.h` (обёртка с AudioQueue), `test_main.c`, `samples/`.
Воспроизведение у MintAI уже есть (`MAVoiceService`: очередь WAV + `AVAudioPlayer`, счётчик
поколений, отмена), а у `VoxSynth.m` при чтении кода нашлось следующее:

1. `isSpeaking` не сбрасывается после естественного конца речи: в `AQOutputCallback` очередь
   только останавливается, но не освобождается, а `_queue != NULL` остаётся истиной до
   следующего `-stop`. У приложения нет события «речь закончилась».
2. Гонка `-stop` -> `-speak:`: `-speak:` сбрасывает `_stopping = NO`, пока старый блок синтеза
   ещё в serial-очереди, и тот продолжает озвучивать СТАРЫЙ текст в новый буфер.
3. `-speak:` на вызывающем (главном) потоке ждёт в `-fillBuffer:` первое готовое
   предложение; предложения делятся только по `.!?`, так что длинный текст без точек
   задерживает старт.
4. `-init` ставит категорию `AVAudioSessionCategoryPlayback`, что конфликтует с
   `PlayAndRecord`, нужной микрофону в `MAVoiceService`.
5. `NSArray<NSString *> *` (lightweight generics) может не собраться старым тулчейном под SDK 6.1.

Если когда-нибудь понадобится потоковое воспроизведение через AudioQueue, эти пункты надо
чинить сначала.
